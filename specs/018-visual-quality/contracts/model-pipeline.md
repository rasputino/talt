# Contract: model pipeline and model keys

## Files

- Models: `src/Talt.Client/Assets/Models/<name>.vox`, embedded as resource `models/<name>.vox`.
  Generated by `dotnet run --project tools/Talt.ModelGen -- [output folder]` (default: that folder);
  may be edited or replaced in MagicaVoxel (keep the palette roles below).
- Assignment: `src/Talt.Client/Rendering/Data/models.json` (comments allowed):

```jsonc
{
  "voxelsPerTile": 8,
  "models": {
    "vehicle": [ { "file": "car.vox", "paint": [16] }, { "file": "bus.vox", "paint": [16] } ],
    "town-building:cottage": [ { "file": "cottage.vox", "glow": [40] } ],
    "industry:coal-mine": [ { "file": "coal-mine.vox" } ],
    "tree:broadleaf": [ { "file": "broadleaf-a.vox" }, { "file": "broadleaf-b.vox" } ],
    "bush": [ { "file": "bush-a.vox" } ],
    "rock": [ { "file": "rock-a.vox" } ]
  }
}
```

## Rules

- Keys are free strings; the renderer looks them up by convention: `vehicle`,
  `town-building:<building type id>`, `industry:<industry kind id>`, `tree:broadleaf|conifer|birch`,
  `bush`, `rock`, `station:<id>`, `depot:<id>`.
- A key with no entry → the caller's placeholder (boxes). A file that is missing or invalid, a palette
  index outside 1–255, a yaw not a multiple of 90, or an empty variant list → start-up error naming
  `models.json`, the key and the reason.
- Variant choice: `variant = hash(object id) % variants.Count` (stable).
- Pivot: centre of the model's base (x and z centre, y = 0). One model voxel = 1/8 tile. A model for
  an N × M tile footprint is N·8 × M·8 voxels; its pivot is placed at the footprint centre on the
  ground.
- Palette roles: indices listed in `paint` are multiplied by the instance tint; indices in `glow` light
  up at night (day/night on); all others are opaque colours as authored.

## Adding a model for a new object kind (feature 010 and later)

1. Add the `.vox` file(s) to `Assets/Models` (or to the generator).
2. Add the key and variants to `models.json`.
3. In the object's instance source, per visible object call
   `modelBatch.Add(entry.Variant(id), position, yawRadians, tint, variation)` where `entry` came from
   `ModelLibrary.TryGet("station:<id>", out entry)`; otherwise keep the placeholder.

No renderer, shader or pipeline change is needed; shadows, LOD, culling and lighting are automatic.
